# Busy Mouse 🐭

A pure CSS and JavaScript animated busy mouse cursor indicator. Features a cute mouse with blinking eyes, swishing tail, spinning busy indicator, and a trailing dot effect.

## Features

- 🐭 Cute animated mouse with realistic movements
- 👀 Blinking eyes
- 🎯 Spinning busy indicator
- ✨ Trailing dot animation
- 🎨 Animated gradient background with pink and orange color cycling
- 📱 Fully responsive
- Pure CSS & JavaScript (no dependencies)

## Live Demo

Open `index.html` in your browser to see the animated busy mouse.

## Animations

- **Pulse**: The mouse body gently pulses
- **Blink**: Eyes blink periodically
- **Swish**: Tail swishes back and forth
- **Spin**: Busy indicator spins continuously
- **Trail**: Dots orbit around the mouse
- **Background Shift**: Animated gradient cycles between pink and orange tones

Perfect for loading screens, processing indicators, or just for fun!
